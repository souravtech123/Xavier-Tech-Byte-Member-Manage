# XTS Member Portal

A centralized society management platform built for **Xavier TechByte Society (XTS), St. Xavier’s College, Ranchi**, to streamline member management, registrations, events, and society activities.

🔗 **Live Demo:** https://xts-member-portal.vercel.app/

## 🚀 Overview

The XTS Member Portal provides a digital platform to manage society operations efficiently, improve member engagement, and organize technical activities within the college community.

## ✨ Features

- **Member Management** — Centralized access to society member information.
- **Registration Management** — Simplified member registration workflows.
- **Event Management** — Support for organizing and managing society events.
- **Society Updates** — A central place for important announcements and activities.
- **Responsive Interface** — Accessible across desktop and mobile devices.

## ⚙️ Getting Started

### Prerequisites

- Node.js and npm
- Git
- Access to the configured database, if required

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd xts-member-portal
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure environment variables in a `.env` file according to your application's requirements.

5. Start the development server:

   ```bash
   npm run dev
   ```

> If your project uses a separate backend, install its dependencies and start the backend separately. Check your `package.json` for the correct commands.
